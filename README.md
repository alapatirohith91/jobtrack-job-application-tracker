# JobTrack — Job Application Tracker

A modern responsive job application tracker built with HTML, CSS and JavaScript. Track applications, interviews, offers and rejections from one dashboard.

## Features
- Dashboard statistics
- Add, edit and delete applications
- Search and status filtering
- Priority and follow-up tracking
- Responsive dark UI
- Local browser persistence
- Export applications to JSON
- GitHub Pages deployment via GitHub Actions

## Live Demo
After GitHub Pages is enabled, the site will be available from the repository Pages URL.

## Tech Stack
HTML5 · CSS3 · Vanilla JavaScript · LocalStorage · GitHub Pages
